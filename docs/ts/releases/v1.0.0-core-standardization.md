## 4. Consumer Integration Notice
Downstream Bun and Node.js applications (`realtime-gateway`) can consume `@dangnmh/logger-ts` via local file linking:
```json
{
  "dependencies": {
    "@dangnmh/logger-ts": "file:../core-kit/ts/logger-ts"
  }
}
```
All emitted logs format as RFC3339 single-line JSON with hoisted `trace_id` and `span_id`.
