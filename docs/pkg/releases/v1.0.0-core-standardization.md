## 1. Release Overview & Shipped Delta

Sprint 1 for the Go Foundation component (`pkg/*`) has completed and verified the full OpenSpec delta:

```diff
ADDED:
+ pkg/logger: DualModeHandler supporting nested "context" key mapping with optional legacy flat mode (LOG_LEGACY_FLAT=true).
+ pkg/httpserver: MaxBytesMiddleware(10MB) bounding inbound HTTP payloads (CONST-SEC-04).
+ pkg/httpserver: BearerTokenAuth startup panic on empty or whitespace tokens (CONST-SEC-01).
+ Root .golangci.yml configuration (v2) with errcheck, govet, ineffassign, staticcheck.

MODIFIED:
! pkg/idutil/nanoid.go: Refactored into deprecated alias delegating directly to pkg/idgen (CONST-02).
! pkg/llm/extractor.go: Refactored to reuse pkg/strutil.TruncateRunes.
! pkg/httpclient/round_tripper_test.go: Added explicit Close handling for 5 HTTP response bodies.
! pkg/ws/client.go & ws_test.go: Handled unhandled connection Close calls.
! docs/pkg/contracts/api.md: Reconciled RingBuffer.Push, Since, and LatestSequenceID signatures.

REMOVED:
- Duplicate random generator logic in pkg/idutil/nanoid.go.
- Redundant private rune truncation function in pkg/llm/extractor.go.
```
