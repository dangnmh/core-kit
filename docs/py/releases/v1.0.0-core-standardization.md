## 4. Consumer Integration Notice
Downstream Python workers (`ai-worker`) can import `logger_py` directly or install in editable mode:
```bash
uv add --editable ../core-kit/py/logger-py
```
All logs automatically correlate with Go and TypeScript traces via hoisted `trace_id` and `span_id`.
